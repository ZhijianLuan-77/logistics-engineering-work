## 为什么建立这个仓库

在本科阶段的学习中，大家都会遇到过**课程资料分散、复习经验难以获取、信息不够对称**的问题。幸运的是，一些学长学姐分享的笔记和学习经验给了我很大帮助，让我在课程学习和备考过程中少走了不少弯路。

在信息平权的今天，我希望通过这样的方式，**减少学习过程中的信息差，让更多同学能够平等、方便地获取学习参考资料**。

因此，我将本科期间积累的部分学习资料整理并开源，希望能为学弟学妹们的课程学习、期末复习和课程设计提供一点参考。

## 资料内容与使用说明

本仓库主要分享我在本科课程学习过程中自行整理或完成的**复习笔记、知识点总结、练习题、模拟试卷、参考答案、课程作业和课程设计**等资料，后续会根据实际情况继续补充。

需要说明的是：

- **尊重教师知识产权。** 本仓库旨在分享个人学习成果，不公开未经授权的教师课件、教学PPT、讲义等资料。如果发现有材料涉及版权或其他权益问题，请联系我，我会及时核实处理。
- **资料并不全面。** 由于选课安排不同，我没有修读专业的所有课程；有些课程即使修读过，自己积累的资料也比较有限，因此本仓库并不涵盖全部课程。
- **内容难免有误。** 受个人知识水平和整理能力所限，部分笔记、习题解答或参考答案可能存在错误和疏漏。所有资料仅供交流与学习参考，不代表官方标准答案，请以任课教师的教学要求为准。
